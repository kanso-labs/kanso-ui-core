# kanso-ui-core

The design data Kanso UI's two component libraries share: the design tokens,
the demo schemes and the glyph paths.
[`@kanso-labs/kanso-ui`](https://github.com/kanso-labs/kanso-ui) draws them on
the web and
[`@kanso-labs/react-native-kanso-ui`](https://github.com/kanso-labs/react-native-kanso-ui)
on iOS and Android.

The package has not been released yet.
